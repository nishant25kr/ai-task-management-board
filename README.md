A collaborative task management app with real-time boards, customizable workflow sections, GitHub repository connections, and AI-powered task execution.

## Features

- Organize work across organizations, boards, and tasks
- Collaborate with live board updates
- Connect a GitHub repository to a board
- Run an agent on a task and review its progress and code changes

## Tech Stack

React, TypeScript, Bun, Express, PostgreSQL, Prisma, and WebSockets.

## Getting Started

Requires Bun and Node.js 18 or later. Configure the required environment variables for your local services, then run:

```bash
bun install
bun dev
```
